# seasonal-agriculture-performance-analysis-project
Data analytics project analyzing seasonal agricultural performance, crop yield, profitability, water efficiency, and rainfall relationships using Python, Pandas, NumPy, Matplotlib, and Seaborn.
# 🌾 Seasonal Agriculture Performance Analysis

## 📊 Major Data Analytics Project

This project focuses on analyzing agricultural performance across different seasons using data analytics and visualization techniques.

The analysis explores seasonal patterns, crop yield, profitability, irrigation methods, water-use efficiency, rainfall relationships, and other agricultural factors to identify meaningful insights that can support better agricultural planning and decision-making.

---

## 📌 Project Overview

Agricultural performance can vary significantly depending on seasonal conditions, crop characteristics, environmental factors, farming practices, resource usage, and economic conditions.

This project analyzes a dataset containing agricultural information from multiple farms and identifies important patterns and relationships related to:

- Crop yield
- Agricultural seasons
- Farm production
- Profitability
- Rainfall
- Temperature
- Soil conditions
- Irrigation methods
- Fertilizer and pesticide usage
- Water consumption
- Water-use efficiency
- Disease and pest risk

The project uses Python-based data analysis and visualization techniques to transform raw agricultural data into meaningful insights.

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Analyze agricultural performance across different seasons.
2. Compare average crop yield between seasons.
3. Analyze profitability across agricultural seasons.
4. Compare the productivity of different crops.
5. Analyze water-use efficiency across irrigation methods.
6. Study the relationship between rainfall and crop yield.
7. Identify important patterns and variations in agricultural performance.
8. Generate data-driven insights that can support agricultural planning and resource management.

## 📂 Dataset

The dataset contains **4,000 records and 28 variables** related to agricultural performance.

### Dataset Features

| Feature | Description |
|---|---|
| Farm_ID | Unique identifier for each farm |
| State | State where the farm is located |
| District | District where the farm is located |
| Crop | Crop cultivated on the farm |
| Season | Agricultural season |
| Farm_Area_Hectares | Farm area in hectares |
| Rainfall_mm | Rainfall received in millimeters |
| Avg_Temperature_C | Average temperature |
| Humidity_pct | Humidity percentage |
| Sunlight_Hours_Day | Average daily sunlight hours |
| Soil_pH | Soil pH value |
| Soil_Moisture_pct | Soil moisture percentage |
| Nitrogen_kg_ha | Nitrogen application |
| Phosphorus_kg_ha | Phosphorus application |
| Potassium_kg_ha | Potassium application |
| Irrigation_Method | Method of irrigation |
| Fertilizer_kg_ha | Fertilizer usage |
| Pesticide_Litre_ha | Pesticide usage |
| Seed_Quality_Score | Seed quality score |
| Yield_Tonnes_Ha | Crop yield per hectare |
| Production_Tonnes | Total agricultural production |
| Market_Price_INR_Tonne | Market price per tonne |
| Total_Cost_INR | Total production cost |
| Revenue_INR | Total revenue |
| Profit_INR | Profit generated |
| Water_Used_m3 | Water used in cubic meters |
| Water_Efficiency_t_per_1000m3 | Water-use efficiency |
| Disease_Pest_Risk_pct | Disease and pest risk percentage |
